# Casa Rio Cerimonial

Site separado da Casa Rio Cerimonial, em Buraquinho, Lauro de Freitas. HTML, CSS e JavaScript; sem dependências de execução.

## Publicação
`npm run build` prepara `dist`. O `vercel.json` configura o build e a pasta de saída. Importe este repositório na Vercel.

## Identidade e conteúdo
Identidade baseada no logo público do Instagram @casariocerimonial: verde-petróleo, dourado e assinatura clara. O arquivo de logo disponível tem 150 × 150 pixels e é exibido em tamanho pequeno, sem ampliação artificial. Substituir pelo original vetorial quando fornecido.

Fotos reais do casamento de Endy e Marlom na Casa Rio, por Garcêz Fotografia. Arquivos preservados com 1200 pixels de largura, sem redimensionamento ou recompressão. As imagens usam proporções preservadas, com recorte adaptado ao layout. Créditos e link para o álbum no rodapé.
Fonte: https://www.garcezfotografia.com.br/portfolio/casamentos/1394475-endy-e-marlom
Estrutura: informações publicadas em https://cerimonialcasario.com/.
Contato principal e endereço: perfil público https://www.instagram.com/casariocerimonial/.

## Interações
Transição dia/noite; escolha de casamento/aniversário integrada ao formulário; galeria modal com setas, teclado e Escape; menu móvel; detalhes expansíveis; formulário prepara pedido no WhatsApp; movimento reduzido respeita a preferência do sistema. Não há reserva automática nem armazenamento de dados no servidor.
